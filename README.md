# Pokédex e tipi (versione web statica)

Sito statico in Angular 20: elenco di tutti i 1025 Pokémon (10 per pagina, con ricerca per nome e filtro per tipo) e una pagina con le debolezze dei 18 tipi, con spiegazioni in italiano e un quiz di ripasso.

I dati sono in `public/data/*.json`: nessun backend, tutto funziona nel browser. Si pubblica su GitHub Pages a ogni push su `main`.

## Sviluppo

```
npm install
npm start
```
